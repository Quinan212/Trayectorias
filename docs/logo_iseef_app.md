# Logo del ISEEF para Trayectorias

Fuente: [escudo publicado por el ISEEF de Concordia](https://iseef-ers.infd.edu.ar/sitio/escudo-iseef_2012_cmyk-2/).

Archivo de referencia: https://iseef-ers.infd.edu.ar/sitio/wp-content/uploads/2018/11/Escudo-ISEEF_2012_cmyk-1000x792.jpg

Recurso de la app: `assets/career_icons/logo_iseef.png` (PNG transparente, 1254 × 1254).

Adaptación para pantallas pequeñas: conserva el escudo, sus cuatro cuadrantes, la «I» roja, el corredor y los colores azul y plata. La cinta muestra «ISEEF»; se quitaron los textos secundarios pequeños. La tarjeta institucional utiliza escala 1.0 para mostrar el escudo completo.

Se asignó a la carrera Educación Física, a la institución ISEEF y a su tarjeta de correlatividades.

Herramienta utilizada: edición de imágenes integrada (`image_gen`), con la imagen original como referencia y fondo transparente. El recurso original permanece intacto.
